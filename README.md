# MY PT — 나만의 PT · 영양 코치

헬스장에서 혼자서도 PT 받듯이 운동하도록 돕는 개인용 웹앱입니다. 운동 루틴, 정확한 자세, 식단·영양제, 인바디 분석, 출석 관리를 하나로 묶었습니다.
설치나 빌드 없이 HTML/CSS/JS만으로 동작하며 **모바일과 PC 모두** 지원합니다. 모든 데이터는 내 기기 안에만 저장됩니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| **트레이너 캐릭터** | 30대 초반 한국인 남/녀 트레이너(강 코치 · 윤 코치). 설정에서 언제든 바꿀 수 있고 이름도 바꿀 수 있어요. 상황별로 코칭 멘트를 해 줘요. |
| **온보딩** | 코치 선택 → 성별·나이·키·체중 → 목표 체중·감량 속도 → 주 몇 회·요일·시간 순서로 입력해요. 주중 최소 2회를 지켜야 다음으로 넘어가요. |
| **12주 프로그램** | 적응기 → 기초 근력 → 강화기. 단계는 달력이 아니라 **실제로 완료한 운동 횟수**를 기준으로 올라가요. 주 2~5회에 맞춰 전신 A/B/C 또는 상·하체 분할 루틴이 나와요. |
| **스케줄 + 이유 설명** | 요일마다 왜 그날 운동하는지 설명해요(48시간 회복, 주중 2회 원칙 등). |
| **약속 생김 → 대체일** | 회복 간격과 주중 2회 원칙에 맞춰 대체일을 점수로 추천해요. 연속일이 되면 세트를 자동으로 1개 줄여요. 건너뛰어도 루틴 순서는 그대로 이어져요. |
| **가이드 운동 모드** | 워밍업 → 세트(목표 무게×횟수, 체크포인트 3개) → 휴식 타이머 → 난이도 평가 → 유산소(경사·속도·시간 타이머) → 쿨다운 → 완료 도장 순서로 진행돼요. 단계마다 직접 눌러야 다음으로 넘어가요. 화면 꺼짐도 막아 줘요. |
| **무게 자동 조정** | 운동 후 '할만했다 / 조금 어려웠다 / 너무 힘들었다'를 고르면 이중 점진 과부하 규칙으로 다음 무게·횟수를 다시 정해요. **무게 테스트**에 예) 데드리프트 20kg×15회 '할만했다'를 입력하면 추정 1RM을 구해 지금 단계에 맞는 무게·횟수·세트를 새로 짜 줘요. |
| **유산소 세팅값** | 트레드밀 경사·속도·시간(예: 경사 12% · 4.5km/h · 30분), 사이클·일립티컬·스텝밀 레벨을 12단계로 처방해요. 목표 심박(최대심박의 60~70%)과 예상 소모 칼로리(ACSM 공식)도 보여 줘요. |
| **자세 모아보기** | 운동 30종(하체·가슴·등·어깨·팔·코어·유산소·스트레칭). 각 운동에 시작/끝 자세 이미지(주동근 주황색 표시), 세팅법, 동작 순서, 체크포인트, 흔한 실수, 호흡, 대체 운동을 담았어요. |
| **식단** | 기초대사량(인바디 실측 → 제지방량 공식 → Mifflin 공식 순), 활동계수, 감량 적자로 하루 칼로리를 정해요. 단백질은 제지방량×2.2g, 운동일은 +100kcal예요. 메뉴 18종의 양을 목표에 맞춰 자동으로 계산하고 메뉴를 바꿀 수 있어요. 물 기록, 음식 가이드, 외식·회식 가이드도 있어요. |
| **영양제(약사 관점)** | 근거 수준 순으로 웨이·크레아틴·오메가3·비타민D·마그네슘·종합비타민·차전자피의 용량, 복용 시간, 주의사항을 정리했어요. 비추천 다이어트 보조제 목록과 복용 체크도 있어요. |
| **인바디** | 결과지 사진을 올리면 원본을 저장하고 OCR(한국어+영어)로 체중·골격근량·체지방량·체지방률·BMI·내장지방·기초대사량·점수 등을 자동으로 읽어요. 저장 전에 확인하고 고칠 수 있어요. 월별 추이 그래프, 감량의 질(지방 비율), 속도 분석, 목표 도달 예상일, 칼로리 보정 추천도 해 줘요. |
| **출석 · 경험치** | 월별 출석 도장 달력, 레벨·칭호, 배지 20종이 있어요. 주간 목표, 주중 2회, 연속 주, 대체일 출석 보너스도 받아요. |
| **알람** | 앱을 열어 두면 설정한 시간과 미리 알림 시간에 소리·진동·시스템 알림이 울려요. 앱을 닫아도 울리게 하려면 **캘린더(.ics) 내보내기**로 8주치 일정을 휴대폰 캘린더에 넣어 두세요. |

## 실행 방법

### 1) PC에서 바로 열기
`index.html`을 더블클릭하면 열려요. 다만 `file://` 환경에서는 알림, 오프라인 설치(PWA)를 쓸 수 없어요. OCR은 인터넷이 연결돼 있어야 CDN에서 엔진을 받아 와요.

### 2) 로컬 서버 (권장)
```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

### 3) 휴대폰에서 쓰기 — GitHub Pages
1. GitHub 저장소 **Settings → Pages**에서 *Deploy from a branch*를 고르고, 브랜치와 `/ (root)`를 선택해요.
2. 생성된 주소(`https://<아이디>.github.io/<저장소>/`)를 휴대폰에서 열어요.
3. **홈 화면에 추가**하면 앱처럼 실행돼요.
   - iPhone: Safari → 공유 → 홈 화면에 추가
   - Android: Chrome → 메뉴 → 앱 설치(홈 화면에 추가)

> 데이터는 기기마다 따로 저장돼요. PC ↔ 휴대폰으로 옮기려면 **설정 → 백업 내보내기 / 불러오기**를 쓰세요. 인바디 원본 사진도 백업 파일에 같이 들어가요.

## 계산 로직 요약
- **칼로리**: BMR × (1.25 + 0.05 × 주간 운동 횟수) × (1 − 적자율 15/20/25%), 기초대사량 아래로는 내리지 않아요. 운동일 +100kcal, 쉬는 날은 주간 평균이 맞도록 조금 줄여요.
- **매크로**: 단백질 = 제지방량 × 2.2g (체중 × 1.3~2.0g 범위), 지방 28%, 나머지는 탄수화물이에요.
- **무게 테스트**: 추정 1RM = 무게 × (1 + (반복 + 남은 여유 횟수) / 30)이에요. 평가별 남은 여유 횟수는 할만했다 5회, 조금 어려웠다 2회, 너무 힘들었다 0회로 봐요. 이 1RM에서 현재 단계의 목표 반복과 여유 횟수에 맞는 무게를 역산해요.
- **세션 후 조정**: '할만했다'면 무게를 한 단계 올려요(증량 폭이 15%를 넘으면 반복부터 늘려요). '조금 어려웠다'에 목표 횟수를 다 채웠다면 +1회 하고, 최대 반복에 닿으면 무게를 올리고 횟수를 처음으로 돌려요. '너무 힘들었다'에 횟수를 못 채웠거나 2회 연속이면 무게를 약 10% 내려요.
- **유산소**: 평가에 따라 레벨이 +1 / +0.5 / −1 바뀌어요. 단계별 상한이 있어요(적응기 7, 기초 근력 10, 강화기 12).
