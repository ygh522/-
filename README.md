# MY PT — 나만의 PT · 영양 코치

헬스장에서 혼자서도 PT 받듯이 운동하도록 돕는 개인용 웹앱이에요. 운동 루틴, 정확한 자세, 식단·영양제, 인바디 분석, 출석 관리를 하나로 묶었어요.
**나와 여자친구 두 사람**이 각자 자기 기록으로 똑같이 쓰고, **휴대폰과 PC의 기록이 자동으로 맞춰져요.**

- **휴대폰(세로 고정)**: 헬스장에서 바로 따라 하는 화면이에요. 오늘 할 운동을 큰 자세 이미지로 넘겨 보고, "운동 시작"을 누르면 세트·휴식·평가를 한 단계씩 안내해요.
- **PC(16:9)**: 정보를 보는 화면이에요. 대시보드(오늘·이번 주·레벨·체중 추이·최근 기록·식단), 운동 일지 표, 바디·인바디 분석, 운동 방법(목록 | 큰 이미지 | 설명 3단)을 한눈에 봐요.
- 디자인은 **블랙 앤 화이트, 각진 UI**예요. 포인트 컬러(주황)는 지금 쓰는 근육, 오늘 목표 횟수처럼 꼭 필요한 곳에만 써요.

## 쓰는 방법 (추천: claude.ai 링크 하나로)

가장 쉬운 방법은 **claude.ai에 올린 MY PT 링크** 하나를 휴대폰과 PC에서 같이 여는 거예요. 따로 서버나 설치가 필요 없어요.

1. 휴대폰과 PC에서 같은 claude.ai 계정으로 로그인하고 MY PT 링크를 열어요. 휴대폰은 홈 화면에 추가해 두면 편해요.
2. 처음 열면 코치 선택 → 기본 정보 → 목표 → 스케줄 순서로 설정해요.
3. 그다음부터는 어느 기기에서 기록해도 다른 기기에 바로 반영돼요. 헬스장에서 신호가 약하면 휴대폰에 먼저 저장했다가 연결되면 올려요.

**여자친구 초대하기**
1. claude.ai에서 MY PT 아티팩트의 **공유(Share)** → **이메일로 초대**를 고르고 권한을 **편집자(Editor)**로 정해요.
   공개 링크로 공유하면 보기만 가능해서 기록이 저장되지 않으니 꼭 이메일 초대로 해 주세요.
2. 여자친구가 자기 claude.ai 계정으로 링크를 열면 자기만의 온보딩부터 시작해요. 운동·식단·체중·인바디 기록은 **각자 따로** 저장되고 서로 볼 수 없어요.
3. 서로 보이는 건 홈 화면(PC는 THIS WEEK 칸의 TOGETHER)에 나오는 요약뿐이에요: 이름, 레벨, 이번 주 출석, 연속 주, 마지막 운동일.

> 자세 이미지는 처음엔 내 성별에 맞는 인물로 보여요. 운동 화면의 **남 / 여** 버튼이나 설정 → 운동 이미지 모델에서 바꿀 수 있어요.

### 다른 방법: 파일로 열기 · GitHub Pages
claude.ai 밖에서 열면 기록이 그 기기에만 저장돼요. 한 기기를 둘이 같이 쓰면 설정 → 함께 쓰기 · 동기화에서 **프로필**을 나눠 쓸 수 있어요. 기기를 옮길 땐 설정 → 데이터 · 백업의 **백업 내보내기 / 불러오기**를 써요(인바디 원본 사진도 같이 옮겨져요).
```bash
python3 -m http.server 8000      # 브라우저에서 http://localhost:8000
```
GitHub Pages: 저장소 **Settings → Pages**에서 브랜치와 `/ (root)`를 고르면 생기는 주소를 휴대폰에서 열고 홈 화면에 추가해요.

## 주요 기능

| 기능 | 내용 |
|---|---|
| **자세 가이드 (가장 중요)** | 헬스장 기구·프리웨이트·맨몸 운동 30종이에요. 모든 운동에 **남성/여성 인물 이미지**가 따로 있어요. 위는 시작 자세(START), 아래는 끝 자세(FINISH)이고 지금 쓰는 근육은 주황색으로 칠했어요. 사진 속 **번호 ①②③은 화면의 체크포인트 3개와 그대로 연결**돼서 이미지만 봐도 자세를 알 수 있어요. 기구 세팅, 동작 순서, 흔한 실수, 호흡, 대체 운동도 함께 있어요. |
| **처방 (무게·횟수·세트·휴식)** | 운동마다 오늘의 무게 × 횟수 × 세트, 휴식 시간, 템포를 보여 줘요. 처음 하는 성인 기준 **남성/여성 첫 세션 추천 무게**(예: 데드리프트 남 30kg · 여 20kg)도 같이 적었어요. |
| **무게 자동 조정** | 세트가 끝나면 '할만했다 / 조금 어려웠다 / 너무 힘들었다'를 고르면 다음 무게·횟수를 다시 정해요. **무게 테스트**에 예) 데드리프트 20kg × 15회 '할만했다'를 넣으면 추정 1RM으로 지금 단계에 맞는 처방을 새로 짜 줘요. |
| **가이드 운동 모드** | 워밍업 → 세트(큰 자세 이미지 + 목표 횟수) → 휴식 타이머 → 평가 → 유산소(경사·속도·시간 타이머) → 쿨다운 → 출석 도장 순서예요. 단계마다 직접 눌러야 넘어가고 화면 꺼짐도 막아 줘요. |
| **12주 프로그램 · 스케줄** | 적응기 → 기초 근력 → 강화기. 실제로 완료한 운동 횟수를 기준으로 단계가 올라가요. 요일마다 그날 운동하는 이유를 보여 주고, 약속이 생기면 48시간 회복과 **주중 최소 2회**를 지키는 대체일을 추천해요. |
| **유산소 세팅값** | 트레드밀 경사·속도·시간(예: 경사 12% · 4km/h · 30분), 사이클·일립티컬·스텝밀 레벨, 목표 심박, 예상 소모 칼로리를 처방해요. |
| **쉬운 식단** | 저울·요리 없이 지키는 식단이에요. 끼니마다 편의점·5분 조리·외식·배달 같은 쉬운 메뉴 2~3개 중 **하나만 고르면** 내 칼로리에 맞는 양(S/M/L)이 공기·개·컵·손바닥 단위로 나와요. 하루 체크 5개(단백질·밥 양·단 음료·물·야식), 물 8컵, 바꿔 먹기, 외식·회식 가이드도 있어요. 하루 칼로리와 단백질은 기초대사량과 감량 속도로 계산해요. |
| **영양제 (약사 관점)** | 근거 수준 순으로 웨이·크레아틴·오메가3·비타민D·마그네슘·종합비타민·차전자피의 용량, 복용 시간, 주의사항을 정리했어요. 피해야 할 다이어트 보조제 목록도 있어요. |
| **인바디** | 결과지 사진을 올리면 **원본을 그대로 저장**하고 체중·골격근량·체지방량·체지방률·BMI·내장지방·기초대사량·점수를 자동으로 읽어요. claude.ai에서는 Claude가 사진을 읽고, 그 밖에서는 내장 OCR(Tesseract)을 써요. 저장 전에 확인하고 고칠 수 있어요. 월별 추이 그래프와 감량의 질·속도 분석, 칼로리 보정 추천도 해 줘요. |
| **트레이너 캐릭터** | 30대 초반 한국인 남/녀 트레이너(강 코치 · 윤 코치) 중 고르고 언제든 바꿀 수 있어요. 상황별 코칭 멘트를 해 줘요. |
| **출석 · 경험치** | 출석 도장 달력, 레벨·칭호, 배지, 주간 목표·연속 주 보너스가 있어요. |
| **알람** | 앱이 열려 있으면 운동 시간과 미리 알림 시간에 소리·진동·알림이 울려요. 앱을 닫아도 울리게 하려면 **캘린더(.ics) 내보내기**로 일정을 휴대폰 캘린더에 넣어 두세요. |

## 계산 로직 요약
- **칼로리**: 기초대사량(인바디 실측 → 제지방량 공식 → Mifflin 공식 순) × 활동계수 × (1 − 적자율 15/20/25%). 기초대사량 아래로는 내리지 않고, 운동하는 날은 +100kcal이에요.
- **단백질**: 제지방량 × 2.2g (체중 × 1.3~2.0g 범위). 화면에는 "손바닥 몇 번"으로도 보여 줘요.
- **식단 분량**: 하루 목표가 1,700kcal 미만이면 S, 2,100kcal 미만이면 M, 그 이상이면 L 분량이에요.
- **무게 테스트**: 추정 1RM = 무게 × (1 + (반복 + 남은 여유 횟수) / 30). 남은 여유 횟수는 할만했다 5, 조금 어려웠다 2, 너무 힘들었다 0으로 봐요.
- **세션 후 조정**: 할만했다 → 무게 한 단계 증가. 조금 어려웠다 + 목표 달성 → 1회 증가(최대 반복에 닿으면 무게 증가). 너무 힘들었다 + 미달이 2회 이어지면 → 무게 약 10% 감소.

## claude.ai 버전 다시 올리기
```bash
python3 tools/build_artifact.py dist   # dist/ 에 claude.ai용 파일을 만들어요
```
`dist/index.html`을 페이지로, 나머지 파일을 같은 경로로 함께 올려요. 기능은 `db`(기록 동기화), `user`(로그인한 사람 구분), `assets`(인바디 원본 사진), `sample`(Claude가 인바디 결과지 읽기), `downloads`(백업·캘린더 파일)를 써요. 같은 아티팩트 주소에 다시 올리면 기록은 그대로 남아요.
